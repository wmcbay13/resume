# Will McBay Resume

This repository contains the source for Will McBay's personal resume website. It presents a concise overview of his experience designing and operating cloud infrastructure, automating engineering workflows, and improving the reliability of SaaS environments.

## What It Describes

- Professional summary as a cloud applications, infrastructure, and site reliability engineer
- Work experience from IT support and systems administration through engineering management and cloud architecture
- Experience with AWS, Azure, Google Cloud, Terraform, Kubernetes, Docker, CI/CD, observability, and infrastructure automation
- Industry certifications, including AWS, Google Cloud, Terraform, and JAMF credentials
- Education and professional contact links, including GitHub, LinkedIn, and email

## Project Structure

- `index.html` contains the resume content and links to contact and professional profiles.
- `style.css` defines the responsive two-column presentation and print-friendly visual styling.
- The site is hosted on GitHub Pages and uses CI/CD to deploy updates whenever changes are pushed to the `main` branch.
